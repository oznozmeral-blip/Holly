# Holly

Holly'nin Windows kurulum dosyaları ve sürüm notları [Releases](https://github.com/oznozmeral-blip/Holly/releases) sayfasında yayımlanır.

## Kurulum

Sürümün **Assets** bölümünden `Holly_Setup.exe` dosyasını indirip çalıştırın. Holly'yi açtıktan sonra yeni kullanıcı adınız ve lisans anahtarınızla kayıt olun.
